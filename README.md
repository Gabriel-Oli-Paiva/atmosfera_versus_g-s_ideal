# Atmosfera versus gás ideal: uma avaliação experimental dos limites do modelo termodinâmico
Este repositório contém os códigos utilizados no trabalho desde a captação dos dados do sensor utilizando o Arduíno, até o armazenamento, tratamento, e análise dos dados utilizando Python. Os códigos também incluem gráficos para análise e visualização dos conceitos abordados.
