# Atmosfera versus gás ideal: uma avaliação experimental dos limites do modelo termodinâmico

**Introdução:** Este repositório contém os códigos utilizados no trabalho desde a captação dos dados do sensor utilizando o Arduíno, até o armazenamento, tratamento, e análise dos dados utilizando Python. Os códigos também incluem gráficos para análise e visualização dos conceitos abordados. 

**Alunos:** Bruna Henrique Fujihashi, Gabriel de Oliveira Paiva e Giovanna Avellar Machado

**Orientador:** Prof. Dr.Leandro Merces

**Resumo:** O conceito de gás ideal desempenha um papel fundamental no ensino de Física, contribuindo para a compreensão da natureza dos modelos científicos e de suas limitações. Nesse contexto, este trabalho propõe uma abordagem didática voltada ao aprofundamento desse entendimento, por meio da integração de atividades experimentais e interdisciplinares, com o objetivo de compreender os limites de validade do modelo idealizado a partir de um sistema real. A metodologia empregada combina conhecimentos de computação para a programação e aquisição de dados com Arduino, técnicas de análise estatística e tratamento de dados utilizando Python, além do estudo de sistemas e modelos físicos para a interpretação dos resultados obtidos. No experimento, o gás atmosférico foi aquecido em um recipiente fechado submerso em água, de modo que a troca de calor ocorresse de forma gradual e uniforme. Foi desenvolvida uma prática experimental de baixo custo e fácil implementação, aplicável a diferentes níveis de ensino e capaz de promover uma compreensão mais ampla dos conceitos envolvidos nos modelos de gás utilizados na Termodinâmica e suas respectivas limitações
